# Haven 0.66.2: Haven's own effects (experimental)

**Haven can now draw furnishing effects itself**, without Stagehand: flames, steam, water, sparkles, an arcade machine's flash. It's the second step towards Haven no longer needing Stagehand, after lights, and it's off unless you turn it on: Settings → Advanced → Effects → **Draw furnishing effects with Haven (experimental)**.

With it on, the same effects show at the same places and times as before; Stagehand still plays furnishing sounds and draws imported Stagehand objects. Turning it off goes straight back. If an effect looks different with it on, please say which furnishing.

An effect file is only used if your game has it, so a free trial never asks for Endwalker or Dawntrail files.

**Fewer empty World pieces.** 1,550 pieces of the World catalogue that drew no thumbnail are no longer listed: water surfaces that don't show in a home, and specks, wires and fences spread over hundreds of metres (Aglaia piece 2 was a patch of sky nearly a kilometre wide). A home that already has one still loads it.

This release changes Haven only; the relay is unchanged.
