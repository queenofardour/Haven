# Haven 0.65.2: invite-only accounts

**Haven's source is now public**, at [github.com/queenofardour/Haven](https://github.com/queenofardour/Haven), with a page on [what Haven does and sends](https://github.com/queenofardour/Haven/blob/main/docs/SAFETY.md).

**New accounts need an access code.** Hosting and joining gatherings still need a Haven account. A Discord account signing in for the first time is now asked, on the sign-in page, for a one-time access code from the maintainer. Accounts that already exist sign in as before, with no code. Haven's sign-in dialog now says so.

Client only: the relay is unchanged.
