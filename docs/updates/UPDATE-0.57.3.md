# Haven 0.57.3: quieter logs for plugin developers

**No more hook warnings.** Players whose Dalamud checks plugins' hooks (a setting plugin developers often turn on) saw eleven "Hook verification failed" errors from Haven when it loaded, for the friend list and party features it lets work inside a home. Haven now attaches to those game functions exactly as the game's documentation describes them. Nothing changes in what you can do.

This update needs no relay change: everyone on 0.57.x can play with you.
