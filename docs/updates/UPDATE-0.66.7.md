# Haven 0.66.7: Haven's sounds by default, and world sets' sounds

**Haven now plays furnishing sounds itself by default**: fountains, fires, chimes, clicks, instruments and an arcade machine's punch, after testing showed them the same as before. With lights and effects already Haven's own, Stagehand now only draws imported Stagehand objects. If a sound seems wrong, Settings → Advanced → Sounds → **Use Stagehand's sounds instead** goes back to the old way.

**World sets bring their sounds.** 367 sets in the World catalogue have always-on sounds of their own (a fountain's trickle, a forge's roar), and they now play when placed. A small note in a tile's corner marks them, beside the bulb and sparkle, and the **Has sounds** filter lists only those. A world piece's sounds play at full volume for now.

The World list is rebuilt once to learn which sets have sounds, which takes a few seconds the first time you open it.

This release changes Haven only; the relay is unchanged.
