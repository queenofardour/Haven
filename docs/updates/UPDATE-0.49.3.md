# Haven 0.49.3: a loading screen, a download bar, and Haven's windows in front

**A loading screen.** Entering or hosting from the launcher now fades the game out, shows the district's loading art with your home's name and what's loading (the room, then the furnishings with a count), and fades back in once everything is drawn. Joining a gathering and leaving a home show it too. It never holds the visit up and always lifts by itself.

**See when custom content is downloading.** When you visit a home with custom content you agreed to load, a bar under the toolbar shows what's coming (furniture, animations, songs, pictures), how many items and how many MB, then "Custom content ready". While the loading screen is up it waits up to 20 seconds for the downloads, with **Continue without waiting** if you'd rather go in.

**Haven's windows stay in front.** The toolbar, placement bar, panels, inspector, pose ball panel, prompts and game windows no longer hide behind Chat 2 or other plugins' windows. Typing in your chat window still works as before. (The game's own windows, like a minigame's meter, always sit under every plugin window; Haven can't lift those.)

Client only: works with relay 0.32.0.
