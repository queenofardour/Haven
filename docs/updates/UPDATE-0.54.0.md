# Haven 0.54.0: NPC levels

**NPCs can have a level.** The NPCs panel has a Level field under the name. Type 1 to 100 and the NPC's nameplate shows it ("Lv90 Maid Bnuuy"), as does the target bar when it's targeted. Leave it empty for no level, as before.

**For testing modded NPCs: `/haven syncprobe`.** A first step towards NPCs wearing Penumbra mods that your guests see too. Stand near a friend you're synced with (Lightless, PlayerSync, Snowcloak) and type `/haven syncprobe Firstname Lastname`, or target them and type `/haven syncprobe`. Haven lists in chat how many of their files come from mods and which folders they come from on your PC. It changes nothing. The full list goes to Haven's log.

This update comes with relay 0.37.0 (housing protocol 33). Older Haven versions can't join gatherings on the new relay, so everyone needs to update.
