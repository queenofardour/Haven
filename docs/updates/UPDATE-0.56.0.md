# Haven 0.56.0: moving pieces properly, the outer shell, a working Exit

**Moving a piece of the house no longer leaves a copy behind.** "Move it" now remembers which piece it moved. **Put it back where it was** returns the original and removes the moved one, instead of leaving you with an extra pillar. Cancel a move, or set the piece down where it stood, and nothing changes. Moved pieces show as "Moved elsewhere" in the removed list.

**Remove the outer shell.** The brown hull around the whole house is now a piece you can remove: point past the walls at it. Without it you can see out into the space beyond, and build there. Outdoor light may reach in.

**The Exit takes you out.** Clicking the house's Exit marker now leaves the home, as it does in a real house.

**No more phantom door.** The free company door to the additional chambers only exists in a company's house, so Haven no longer offers it to remodel. Your front door is still there, and still removable.

**Smaller fixes.**
- A removed window's light shaft stays gone.
- The ceiling and structure piece offers to take only its own floor's pillars and beams with it.

This update comes with relay 0.39.0 (housing protocol 35). Older Haven versions can't join gatherings on the new relay, so everyone needs to update.
