# Haven 0.57.0: NPCs with Customize+ bodies

**Shape an NPC with Customize+.** In the NPCs panel, **Customize+ profile…** lists your Customize+ profiles: pick one and the NPC's body takes its shape. The profile is kept with your home, so every guest who has Customize+ sees it, whether or not you're paired in a sync plugin. **Copy my look** now also takes the Customize+ profile you're wearing. **Take it away** removes it.

**Everyone needs this update to gather.** Homes now carry Customize+ profiles, so Haven's relay was updated with this release: friends on 0.56.x can't join a gathering until they update.
