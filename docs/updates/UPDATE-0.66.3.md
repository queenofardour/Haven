# Haven 0.66.3: Haven's own effects, fixed

**Haven's own effects should now show.** In 0.66.2, turning on Settings → Advanced → Effects → **Draw furnishing effects with Haven (experimental)** made every flame, fountain and drip disappear: Haven made the effects but never started them. They now start the way Stagehand starts them. The switch is still off unless you turn it on.

This release changes Haven only; the relay is unchanged.
