# Haven 0.53.2: MakePlace layouts keep their paintings and wallpapers

**MakePlace layouts.** Importing a MakePlace layout (Launcher → New home → Import MakePlace layout…) now brings over what each piece shows: a picture frame's painting, a partition's wallpaper, a vase's flower and a canvas's print. These used to arrive blank. If a layout uses something Haven can't show, the piece is still placed, plain, and the import message says how many.

Everything else in a MakePlace layout already came across: every furnishing in its place and turn, dyes, stacked items, and the walls, floors and ceiling lights. Windows and doors stay the house's own, and yard items are left out.

Not yet carried: MakePlace's light level. Haven keeps the new home's usual brightness for now; change it in the Room panel.

This update needs no relay change: everyone on 0.53.x can play with you.
