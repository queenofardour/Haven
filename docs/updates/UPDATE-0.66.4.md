# Haven 0.66.4: Haven's effects by default

**Haven now draws furnishing effects itself by default**: flames, steam, water, sparkles and an arcade machine's flash, after testing showed them the same as before. Stagehand still plays furnishing sounds and draws imported Stagehand objects.

If an effect looks wrong, Settings → Advanced → Effects → **Use Stagehand's effects instead** goes back to the old way, so you can compare. Please say which furnishing if you need it.

This release changes Haven only; the relay is unchanged.
