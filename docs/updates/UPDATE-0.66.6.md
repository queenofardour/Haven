# Haven 0.66.6: no more giant World pieces

**The World catalogue no longer lists pieces too big to furnish with.** 6,078 pieces are over 200 m across, so even at the smallest scale (0.05×) they're still more than 10 m wide: rock outcrops, ridges, mounds, giant spheres, rails kilometres long, towers taller than any room (the purple island rock was one). They're no longer offered. Big pieces that shrink to a sensible size stay, so a red-roofed house still makes a fine miniature. A home that already has one of the giants still loads it.

This release changes Haven only; the relay is unchanged.
