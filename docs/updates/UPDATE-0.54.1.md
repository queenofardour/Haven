# Haven 0.54.1: deletes reach the server

**Deleting your custom content.** If Haven can't reach its server when you delete a picture, song, furnishing or animation (you're offline, the server is busy, or it was just updated), the item is still deleted from your PC, and Haven deletes its copy on the server by itself as soon as it can. It tries again every few minutes, then hourly, as the character that uploaded it. Before, the server copy stayed until it expired after 30 days, and pictures and songs weren't deleted at all.

**More room for custom content.** Each character can now keep 250 MB on Haven's server (was 200 MB), and Haven's shared storage holds 10 GB (was 4 GB). Settings → Custom content shows both.

This update needs no relay change: everyone on 0.54.0 can play with you.
