# Haven 0.66.0: Haven's own lights (experimental)

**Haven can now draw furnishing lights itself**, without Stagehand. This is the first step towards Haven no longer needing Stagehand, and it's off unless you turn it on: Settings → Advanced → Lights → **Draw furnishing lights with Haven (experimental)**.

With it on:
- lamps, chandeliers and every other furnishing light, and the blank canvas's fill light, are drawn by Haven, with the same colour, reach, shadows and patterns as before;
- **world pieces' lights shine**: a World catalogue lantern or lamp post now lights its surroundings (up to 256 such lights per home);
- Stagehand still draws everything else, imported Stagehand objects and their lights included.

Turning it off goes straight back to Stagehand's lights. If a room looks different with it on, please say which room and which lights.

A light's pattern texture is only loaded if your game has it, so a free trial never asks for Endwalker or Dawntrail files.

This release changes Haven only; the relay is unchanged.
