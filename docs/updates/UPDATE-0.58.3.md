# Haven 0.58.3: inn rooms

**Inns as homes.** New home has a new first size, **Inn**, with all eight inn rooms: Mizzenmast (Limsa Lominsa), The Hourglass (Ul'dah), The Roost (Gridania), Cloud Nine (Ishgard), Bokairo Inn (Kugane), The Pendants (the Crystarium), the Andron (Old Sharlayan) and The For'ard Cabins (Tuliyollal). Each comes furnished as the real one.

**Make it yours.** Remodel lists the room's own furniture, from the bed and chairs to the smallest ornament: remove any piece, and put it back whenever you like. Then furnish it as you would any home. Inn pieces can't be moved yet, only removed.

**Inn details.** An inn room has no wallpaper, flooring or brightness to change. Its door takes you out of the home; the bed, armoire, bells, dresser and the like don't answer inside Haven, so they're hidden.

This update needs no relay change: everyone on 0.57.x and 0.58.x can play with you. Friends need this version to join you in an inn.
