# Installing Haven

1. **Install Stagehand** from its own repository (see [stagehandxiv.com](https://stagehandxiv.com)). Install Penumbra too if you want custom pictures, songs, furniture or animations.
2. **Add Haven's repository.** Open `/xlsettings`, go to **Experimental**, and under **Custom Plugin Repositories** add:
   ```
   https://raw.githubusercontent.com/queenofardour/Haven/feed/pluginmaster.json
   ```
   Tick **Enabled** and save.
3. **Install Haven** from `/xlplugins`, then type `/haven` to open it.

Updates arrive through Dalamud's usual update checks. Leave your home before updating.

## Using it on your own

Choose **New home**, pick a shell and create it. Click its card, choose **Just me**, and you're inside. **Furnish** on the toolbar opens the catalogue. **Leave home** (or `/haven leave`) takes you back to where you were.

## Gatherings

Hosting or joining a gathering needs a Haven account:

1. In Haven, open **Settings → Connection** and choose **Sign in with Discord**.
2. Your browser opens Discord. Approve the sign-in, then check that the code on the page matches the one Haven shows.
3. Haven is invite-only for now: a new account is asked for the one-time **access code** you were given. Accounts that already exist don't need one.

To meet up, everyone stands near each other in the game first (for example in the same room or ward), then the host chooses **Host a gathering** and shares the visit code, or invites friends nearby from the Visit panel.

## Uninstalling

Disable or remove Haven in `/xlplugins` while you're outside a home. Your homes stay in Haven's configuration folder unless you delete it.
